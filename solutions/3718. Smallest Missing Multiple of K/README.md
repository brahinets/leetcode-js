# 3718. Smallest Missing Multiple of K

## Easy

Given an integer array `nums` and an integer `k`, return the **smallest positive multiple** of `k` that is
**missing** from `nums`.

A **multiple** of `k` is any positive integer divisible by `k`.

### Constraints:

- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`
- `1 <= k <= 100`
